# Crime Hotspot Prediction & Analytics System

## Overview
This project is a Machine Learning-based Crime Hotspot Prediction and Analytics System developed to predict crime risk levels and identify crime-prone areas. The system helps authorities take preventive actions by analyzing historical crime data and generating alerts for high-risk locations.

## Problem Statement
Traditional crime monitoring relies on manual analysis of historical reports, making proactive crime prevention difficult. This project uses machine learning techniques to predict crime levels and detect hotspot areas for better resource allocation and public safety.

## Business Objective
- Predict Crime Risk Level (Low, Medium, High)
- Identify Crime Hotspots
- Generate Alerts for High-Risk Areas
- Support Data-Driven Decision Making

## Technologies Used

- Pandas
- NumPy
- Scikit-Learn
- Streamlit

- Seaborn

## Machine Learning Model
Random Forest Classifier

## Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Crime Pattern Visualization
- Crime Risk Prediction
- Hotspot Detection
- Alert Generation System

## Dataset Attributes
- City
- Area
- Crime Type
- Population
- Past Crime Count
- Unemployment Rate
- Police Stations
- Weather Conditions
- Month
- Crime Level (Target Variable)

## Key Insights
- Past crime count is a strong predictor of future crime risk.
- Areas with higher unemployment rates tend to have higher crime levels.
- Crime patterns vary across cities and regions.
- Police station availability impacts crime occurrence.

## Recommendations
- Increase police patrols in hotspot areas.
- Allocate additional resources to high-risk regions.
- Monitor locations with increasing crime trends.
- Use predictive alerts for proactive crime prevention.
